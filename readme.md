## Introduction

This course is designed to take you from a complete PHP beginner to a confident developer capable of building dynamic, database-driven web applications. Each module includes theory, code examples, exercises, and mini-projects.

**What you'll learn:**
- PHP syntax, variables, and data types
- Control structures, functions, and arrays
- Object-Oriented Programming (OOP)
- Working with forms and user input
- Sessions, cookies, and authentication
- Connecting to MySQL databases with PDO
- Building a complete CRUD application
- Security best practices (SQL injection, XSS, CSRF)
- Introduction to modern PHP with Composer & frameworks

---

## Prerequisites

Before starting, you should have:

- Basic understanding of HTML & CSS
- Familiarity with how the web works (HTTP, requests/responses)
- A code editor (VS Code, PHPStorm, Sublime Text, etc.)
- PHP 8.0+ installed
- MySQL or MariaDB installed
- Composer installed (for later modules)

## Course Outline

### Module 1 — PHP Basics
- What is PHP & how it works
- Installing PHP & setting up a local server (XAMPP/Laragon)
- PHP syntax, comments, and output (`echo`, `print`)
- Variables, constants, and data types
- Strings, numbers, and operators

### Module 2 — Control Flow
- `if`, `else`, `elseif`
- `switch` statements
- `while`, `do-while`, `for`, `foreach`
- `break` and `continue`

### Module 3 — Functions & Arrays
- Defining and calling functions
- Parameters, return values, default arguments
- Variable scope
- Indexed, associative, and multidimensional arrays
- Array functions (`array_map`, `array_filter`, `array_reduce`, etc.)

### Module 4 — Working with Forms
- Handling `GET` and `POST`
- Validating and sanitizing input
- File uploads
- Form security basics

### Module 5 — Object-Oriented PHP
- Classes and objects
- Properties and methods
- Constructors & destructors
- Inheritance, interfaces, and traits
- Abstract classes
- Namespaces and autoloading

### Module 6 — Sessions, Cookies & Auth
- `$_SESSION` and `$_COOKIE`
- Building a login system
- Password hashing (`password_hash`, `password_verify`)
- Role-based access control

### Module 7 — Databases with PDO
- Connecting to MySQL via PDO
- Prepared statements
- CRUD operations
- Transactions
- Handling errors safely

### Module 8 — Building a CRUD App
- Project: Simple Blog / Task Manager
- Routing basics
- MVC pattern introduction
- Templating
- Flash messages & redirects

### Module 9 — Security Essentials
- SQL injection prevention
- XSS and output escaping
- CSRF tokens
- File upload vulnerabilities
- Secure configuration

### Module 10 — Modern PHP
- Composer & Packagist
- PSR standards
- Introduction to frameworks (Laravel, Symfony, Slim)
- Environment variables with `.env`
